Secp256r1SigVerify Introspection
Instead of expensive custom BPF curve math, Haptix targets Solana's native Secp256r1SigVerify1111111111111111111111111 precompile. The Anchor program inspects the instructions sysvar, validates signature offsets, and enforces canonical low-S normalization (s ≤ n/2) to prevent malleability.
• Private key stays locked in Android StrongBox / Secure Enclave
Out-of-Band Relay Local & Remote
Dual-Device Vault Mode
When high-value transactions trigger 2-of-2 quorum, the mobile app broadcasts an encrypted payload via our relay to a secondary browser/hardware terminal (vault.html). The co-signer approves with Mac Touch ID or YubiKey. Neither device ever shares memory or private keys.
• End-to-end encrypted out-of-band multisig coordination

Users can create and deploy a smart wallet with zero pre-funded SOL. Our embedded paymaster relayer sponsors account rent and drips a 0.20 SOL starter test balance so new users never hit an empty $0.00 screen.
