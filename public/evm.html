Haptix

Your agent spends inside its budget on its own. Anything more needs your fingerprint and your second key.

Why builders use it

Limits that live in the account, not in your agent's code.

The contract checks what a call does

Not just the amount. Each grant lists the addresses the agent may pay, the router and tokens it may trade, a limit per payment and a rolling 24 hour budget. What it buys always comes back to the account.

Over budget becomes a request, not a failure

The SDK sends nothing and returns a request with the exact operation and the agent's signature. You paste it into the wallet and approve it with both passkeys.

No seed phrase and no server key

Two passkeys control the account: one for small sends, both for anything bigger. The chain verifies them natively through the P256 precompile, with no signing service in between.

One key stops every agent

Freeze the account with one passkey and no agent can spend until you unfreeze it with both. Revoking a single agent takes one action.

For agent builders

A few lines give your agent its budget.

The TypeScript SDK reads what is left, pays, swaps, and hands you an approval request for anything bigger.

  • Any ERC-4337 v0.7 bundler. It estimates gas with a placeholder of the approved shape, so one estimate fits both outcomes.
  • Typed refusals. Revoked, expired, frozen and not allowed each throw their own error code.
  • Knows when you approved. It watches the EntryPoint for the operation, whichever bundler the wallet used.
const agent = createHaptixAgent({ rpcUrl, bundlerUrl,
  entryPoint, account, agentKey });

// What's left in the last 24 hours
const b = await agent.budget();

const out = await agent.pay(to, parseEther('0.0001'));

if (out.status === 'needs-approval') {
  // Nothing was sent. Show the owner this request.
  console.log(out.message, out.request);
  await agent.waitForOperation(out.userOpHash, {
    fromBlock: out.fromBlock, nonce: out.nonce });
}

Questions

The hard ones, answered plainly.

Can my agent drain my account?

Not past its grant. The contract checks every operation the agent signs: the addresses, contracts, functions and tokens it may use, a limit per payment, and a rolling 24 hour budget. If the agent's key leaks, the most it can spend is what is left of that budget, and one passkey freezes every agent at once.

How do you know my two passkeys are on different devices?

The contract can't check that, because passkey providers don't prove where a key lives. Two keys that sync through one password manager end up on every device it syncs to. Haptix detects synced keys when you set them up, warns you, and steers you to a second key that can't sync, such as a security key.

MetaMask and Base already offer spending allowances. What's different?

They do, and they came first. The allowances they document are token amounts per period. Haptix limits what a call does too: which contracts, functions, tokens and recipients, and that trade proceeds return to your account. Over budget, the agent's exact operation goes to your two passkeys instead of failing.

Robinhood already lets agents trade. Why this?

Robinhood's agent trading lives inside its brokerage, where Robinhood holds the money and your limit is what you deposit into a separate account. Haptix is for people who hold assets themselves on chain. The budget is enforced by your own account, with no second account to fund.

Is it audited? Can I use it with real money?

No to both, for now. It runs on testnets only and has not had an external audit. The audit comes before mainnet and before real funds.

Do the trades use real liquidity?

Not yet. Robinhood Chain testnet documents no Uniswap deployment, so the trades run through a demo router with worthless demo tokens. The contract accepts any router with the SwapRouter02 interface that you allow.

Can accounts be upgraded?

No. Each account is a minimal clone with no admin key, so nobody can change your rules but you. The cost is that a fix ships as a new factory, and users move to a new account.

Who pays gas?

The account pays for its own operations today. Gas sponsorship through a paymaster is planned before mainnet.

Is this the same Haptix as the Solana mobile wallet?

Same builder, separate product. The Solana mobile wallet runs on Solana Seeker. This is the EVM version: a browser extension and smart account contracts for Robinhood Chain and Arbitrum.
