# Getting Started on Solana Mobile

Setting up a Haptix smart account is fast and completely frictionless. There are no seed phrases to write down or memorize.

---

## 1. Install Haptix Mobile

Haptix is built natively for Android, the **Solana Seeker** phone, and iOS:

- **Android / Seeker:** Download and install the pre-built APK from the GitHub releases or run locally with Expo.
- **Expo Dev Client:**
  ```bash
  cd solana-mobile/haptix-mobile-app
  npm install
  npx expo start
  ```

---

## 2. Create Your Smart Account

1. Open the Haptix app and tap **Create Smart Wallet**.
2. **Primary Passkey Enrollment:** Authenticate with your device biometrics (Fingerprint / Face Unlock / Touch ID). This binds a NIST P-256 public key generated inside your phone's hardware security enclave directly to your wallet account.
3. **Backup Passkey (2-of-2 Quorum):** Generate a secondary backup key (stored on-device or on a secondary FIDO2 key) to unlock high-value Vault transfers and governance settings.

---

## 3. Instant Gasless Onboarding

You do not need to purchase or transfer SOL from an exchange before testing:

- **Sponsored Paymaster:** The Haptix relayer treasury sponsors your initial on-chain account initialization and rent fees on Solana Devnet.
- **Seeker Genesis Reward:** Newly created wallets automatically receive a welcome allocation of **100 SKR** (Seeker tokens) for testing.
- **Devnet Faucet:** Tap **Faucet** in the quick action row to request an instant **+0.1 SOL** airdrop directly to your wallet PDA.

---

## 4. Your First Biometric Transfer

1. Tap **Send** from the home screen.
2. Enter a recipient Solana address and transfer amount:
   - **Low-Value (≤ 0.1 SOL / 20 USDC / 50 SKR):** Confirms with a swift **1-tap biometric passkey**.
   - **Vault Value (> Threshold):** Automatically prompts for your **Vault Key (2-of-2 Quorum)** before submitting to the Solana network.
3. Tap **Send with Passkey** and authenticate. Your transaction is verified on-chain by Solana's native `Secp256r1SigVerify` precompile in milliseconds!
